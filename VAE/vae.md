# Variational Autoencoder (VAE) for Distribution Modeling

## 概述

本项目实现了用于复杂2D分布建模的Variational Autoencoder (VAE)。与Flow-Matching不同，VAE通过学习数据的潜在表示来进行分布建模，提供了一种离散的编码-解码方法。

## VAE核心概念

### 1. 三种关键分布

#### 先验分布 p(z) - "潜在空间的结构假设"
```
p(z) = N(0, I)  (标准正态分布)
```
- **作用**: 定义潜在空间应该具有的结构
- **目的**: 使得我们可以从标准正态分布采样来生成新数据
- **选择原因**: 数学上方便处理，采样简单，中心化且各维度独立

#### 后验分布 q(z|x) - "数据到潜在表示的映射"
```
q(z|x) = N(μ_encoder(x), σ²_encoder(x))
```
- **作用**: Encoder网络学习的从数据到潜在空间的概率映射
- **输出**:
  - μ(x): 给定输入x，潜在变量z的均值
  - σ²(x): 给定输入x，潜在变量z的方差（不确定性）
- **特点**: 这是学习得到的分布，不是预先定义的

#### 生成分布 p(x|z) - "潜在表示到数据的重构"
```
p(x|z) = N(decoder(z), σ²_noise * I)
```
- **作用**: Decoder网络实现的从潜在空间到数据空间的映射
- **含义**: 给定潜在变量z，生成观测数据x的概率分布

### 2. VAE的数学框架

VAE基于**变分推断**，目标是最大化数据的对数似然：

```
目标: 最大化 log p(x) = log ∫ p(x|z) p(z) dz
```

由于积分难以计算，VAE使用**变分下界(ELBO)**：

```
log p(x) ≥ E_{q(z|x)}[log p(x|z)] - KL(q(z|x) || p(z))
            ↑                      ↑
       重构损失                  KL散度损失
```

## VAE损失函数详解

VAE的总损失函数包含两个部分：

```
L_VAE = L_reconstruction + β * L_KL
```

### 1. 重构损失 (Reconstruction Loss)
```
L_reconstruction = ||x - decoder(z)||²
```

**直观理解**:
- 衡量解码器重构原始数据的能力
- 确保编码后再解码能够恢复原始输入
- 对应ELBO中的 E_{q(z|x)}[log p(x|z)] 项

### 2. KL散度损失 (KL Divergence Loss)
```
L_KL = KL(q(z|x) || p(z))
     = KL(N(μ(x), σ²(x)) || N(0, I))
     = -0.5 * Σ[1 + log(σ²) - μ² - σ²]
```

**直观理解**:
- 确保学习到的后验分布接近先验分布
- 正则化潜在空间，防止过度复杂化
- 使得我们可以从先验分布采样进行生成

### 3. β参数的作用

β控制重构质量和潜在空间规整性的平衡：

- **β = 1**: 标准VAE
- **β > 1**: β-VAE，更强调潜在空间规整化
- **β < 1**: 更重视重构质量，允许潜在空间更灵活

**权衡考虑**:
- β太大 → 潜在空间规整但重构质量差（后验塌陷）
- β太小 → 重构质量好但潜在空间混乱，生成质量差

## VAE vs Flow-Matching 对比

| 方面 | VAE | Flow-Matching |
|------|-----|---------------|
| **建模方式** | 离散的编码-解码 | 连续时间的路径学习 |
| **训练目标** | 最大化ELBO | 学习velocity field |
| **潜在空间** | 固定先验分布 | 隐式学习的流形 |
| **生成过程** | z~N(0,I) → decoder(z) | noise → ODE求解 → data |
| **采样速度** | 快速（一次前向传播） | 慢（需要ODE求解器） |
| **可解释性** | 潜在维度有明确语义 | 路径变换较抽象 |
| **训练稳定性** | 相对稳定 | 需要调节采样器参数 |

## 分布建模应用

对于复杂2D分布（spiral, moons, circles等），VAE的设计考虑：

### 架构设计
```python
input_dim = 2        # 2D分布
latent_dim = 2       # 便于可视化，也可以选择更高维度
hidden_dims = [64, 128, 256]  # 足够的表达能力
beta = 0.5          # 平衡重构和正则化
```

### 训练策略
- 监控重构损失和KL损失的比例
- 可视化潜在空间的分布
- 检查生成样本的质量
- 根据需要调整β参数

### 评估指标
- 重构误差 (MSE)
- 生成样本的视觉质量
- 潜在空间的分布规整性
- 插值的平滑性
